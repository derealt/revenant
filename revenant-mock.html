Rate Limiting at Scale: Token Bucket vs. Sliding Window

When building an API gateway that handles millions of requests per second, choosing the right rate limiting algorithm isn't just an implementation detail — it's an architectural decision that affects every downstream service...

The token bucket algorithm works by maintaining a "bucket" of tokens that refills at a constant rate. Each request consumes one token. When the bucket is empty, requests are rejected until tokens refill...
